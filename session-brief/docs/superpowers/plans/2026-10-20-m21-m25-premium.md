# Premium (M21–M25) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per owned name, an implied-volatility regime read (rich / fair / cheap) and a twelve-cell call strip from Cboe's delayed option chain, stored replayably, surfaced on a `/volatility` dashboard, as a gated §6 in the close brief, and as a state-change strip in the open brief.

**Architecture:** A fourth provider protocol (`OptionsProvider`) over a keyless Cboe client, with a deterministic synthetic twin; verbatim-but-banded raw payloads; four new market-data tables; a pure `volatility.py` that does selection, IV30, HV, percentiles and the regime; metrics rows per name; one new section id `premium` at `schema_version` 10 rendered by both existing renderers; a server-rendered Next.js page reading the same tables.

**Tech Stack:** Python 3.12 (`httpx`, `Decimal`, SQLAlchemy Core, Alembic, pytest), Next.js 15 + Drizzle (read-only), React Email, JSON Schema → `pnpm contracts:gen`.

**Spec:** `docs/superpowers/specs/2026-10-20-m21-m25-premium-design.md` (the repo copy); long form at https://claude.ai/artifact/NdDi7eWfHQkRMinn54vNNq.

**Reference implementation:** a throwaway spike of the client, parser, strip selection, IV30 and probe exists at `/private/tmp/claude-501/-Users-shuliu/e1a3d9fe-ad85-4846-bf48-fc75a7d63a94/scratchpad/spike-ref/` (`cboe.py`, `test_cboe.py`, `test_cli_cboe_probe.py`, `cli.diff`). ## Review Focus

1. **Two expiries on the same day as the tenor target with no weekly between them** (a name with only monthlies): `select_strip` must mark `tenor_collapsed` on the second and later tenors rather than silently repeating a cell. Pinned in Task 4.

4. **A stored `schema_version` 9 brief rendered by the v10 templates**: both renderers must treat an absent `premium` section as "not computed" and render byte-identically to today. Pinned in Task 12.
5. **A name whose open-lot shares drop below 100 mid-week**: `contracts_writable` must be recomputed each session from open lots (closed lots excluded) and a 0 must remove the name from the email gate while keeping it in the archive and dashboard. Pinned in Tasks 7 and 11.
