# M13 Attribution Consumers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the M11/M12 attribution residual load-bearing in the product — schedule its batch stages, carry the decomposition into the BriefObject (schema v3) with |resid_z| salience ranking, grade claims against the realized residual, surface theme-misfit/β-instability as maintenance flags, and add a fixture-tested event-concordance check — without re-opening the econometrics.

**Architecture:** Pure functions stay pure and clock-injected (fire-time math, tier/predicate logic, concordance rate). The shared `attribution` table is read at assembly time filtered to held names (the M11/D21 design — no per-user attribution compute). Renderers gain optional columns; old (v2) briefs still render because the new row fields are optional. Money stays integer cents; regression stays float quantized at storage.

**Tech Stack:** Python 3.12, `uv`, SQLAlchemy Core, Alembic, pytest, `mypy --strict`, `ruff`. Next.js 15 / React Email / TypeScript (biome). Postgres 16 (Supabase). Contracts generated by `pnpm contracts:gen`.

## Global Constraints

- **Python owns the schema. Alembic is the only migration path.** The web app never runs DDL. Migration this milestone is `0011_attribution_consumers`.
- **The LLM never produces a number.** Narration writes prose only; the digit-drop guard in `narrate.py` stands unchanged. Any digit in narration output is dropped.
- **Additivity is invariant.** `market_bps + theme_bps + resid_bps == total_bps` per attribution row (M12 stores this; M13 only reads it). Never break it.
- **Money is integer cents; regression is float quantized to `Decimal` at storage.** Never float on the money path.
- **`resid_z` is a true z-score** = `resid_bps / resid_scale` (MAD-scaled), as M12 stores it. `|resid_z|` is the salience score everything ranks on.
- **`ATTRIBUTION_MODEL_VERSION = 2`.** Every attribution read and every claim grade is keyed by `model_version`. v1 rows are never rewritten.
- **Bump `schema_version` on the object shape change and keep old renderers.** `SCHEMA_VERSION` goes 2 → 3. New row fields are OPTIONAL so a v2 brief (which lacks them) still validates and renders.
- **`pnpm contracts:gen` must be clean in CI.** After any schema edit, regenerate both bindings and `git diff --exit-code` must pass. The generator uses `--disable-timestamp`; output is deterministic.
- **Trading days come from `exchange_calendars`.** Never hardcode holidays or a 16:00 close. UTC at rest, `America/New_York` in logic.
- **Injected clock.** Every scheduled job body and every stage takes `now_utc`; never call `datetime.now()` inside pure or job-body functions. The pure fire-time math is unit-tested without a clock.
- **Every table has `user_id`.** Maintenance flags are user-keyed like existing flags.
- **DB tests** use the rolled-back `db_conn` fixture and skip when `DATABASE_URL` is unset; they require `uv run alembic upgrade head` (through `0011`). Pure tests need no DB.
- **Verify commands:** `uv run pytest`, `uv run ruff check worker tests`, `uv run mypy --strict worker`, `pnpm --filter web typecheck`, `pnpm contracts:gen`.

## M13 tunables (module constants, documented as tunable)

- `RESID_MATERIAL_Z = 2.0` — `|resid_z|` at/above which a name is "residual-material": gets full tier regardless of raw move, and satisfies the `material_residual` gating predicate (§5). Single source in `worker/attribution.py`.
- `BETA_INSTABILITY_THRESHOLD = 0.3` — `|beta_drift_20d|` above which β-instability is flagged (spec §4: "β changing >0.3 over 20 sessions").
- `CONCORDANCE_Z = 2.0` — `|resid_z|` at/above which a day is "high-residual" for the concordance check (§6).
- Scheduler ET wall-clock fires: refit Saturday 08:00 ET; PM score 18:30 ET (session days); AM reconcile 07:00 ET (session days).

```python
from datetime import time as _time
from worker.calendar import ET

def _et_fire(d: date, at_et: _time) -> datetime:
    return datetime.combine(d, at_et, tzinfo=ET).astimezone(UTC)

def next_session_fire(now_utc: datetime, at_et: _time) -> datetime:
    """Next trading-session day at ``at_et`` (ET wall-clock), strictly after now."""
    d = calendar.today_et(now_utc)
    for _ in range(8):
        if calendar.is_session(d):
            ft = _et_fire(d, at_et)
            if ft > now_utc:
                return ft
        d = d + timedelta(days=1)
    raise RuntimeError(f"no session fire within 8 days of {now_utc}")  # pragma: no cover

def next_weekly_fire(now_utc: datetime, weekday: int, at_et: _time) -> datetime:
    """Next ``weekday`` (Mon=0..Sun=6) at ``at_et`` (ET), strictly after now."""
    d = calendar.today_et(now_utc)
    for _ in range(8):
        if d.weekday() == weekday:
            ft = _et_fire(d, at_et)
            if ft > now_utc:
                return ft
        d = d + timedelta(days=1)
    raise RuntimeError(f"no weekly fire within 8 days of {now_utc}")  # pragma: no cover
```

```python
def run_refit_job(
    engine: Engine, *, now_utc: datetime,
    model_version: int = ATTRIBUTION_MODEL_VERSION, healthcheck_url: str | None = None,
) -> str:
    """Weekend refit over every scored symbol, at the last completed session."""
    from worker.attribution import refit
    hc = config.HEALTHCHECKS_REFIT_URL if healthcheck_url is None else healthcheck_url
    try:
        fit_date = calendar.previous_session(calendar.today_et(now_utc) + timedelta(days=1))
        with engine.begin() as conn:
            refit(conn, fit_date, now_utc=now_utc, model_version=model_version)
        ping_success(hc)
        return "refit"
    except Exception as exc:
        ping_fail(hc, f"refit {now_utc:%Y-%m-%d}: {exc!r}")
        raise

def run_pm_score_job(
    engine: Engine, *, now_utc: datetime,
    model_version: int = ATTRIBUTION_MODEL_VERSION, healthcheck_url: str | None = None,
) -> str:
    """PM score (provisional/synthetic) for today's session."""
    from worker.attribution import score
    hc = config.HEALTHCHECKS_PM_URL if healthcheck_url is None else healthcheck_url
    session_date = calendar.today_et(now_utc)
    try:
        if not calendar.is_session(session_date):
            ping_success(hc)
            return "skipped-holiday"
        with engine.begin() as conn:
            score(conn, session_date, now_utc=now_utc,
                  model_version=model_version, synthetic=True)
        ping_success(hc)
        return "pm-scored"
    except Exception as exc:
        ping_fail(hc, f"pm-score {session_date}: {exc!r}")
        raise

def run_reconcile_job(
    engine: Engine, *, now_utc: datetime,
    model_version: int = ATTRIBUTION_MODEL_VERSION, healthcheck_url: str | None = None,
) -> str:
    """AM reconcile of the prior session's synthetic rows against the official bar."""
    from worker.reconcile import reconcile
    hc = config.HEALTHCHECKS_AM_URL if healthcheck_url is None else healthcheck_url
    today = calendar.today_et(now_utc)
    try:
        if not calendar.is_session(today):
            ping_success(hc)
            return "skipped-holiday"
        trade_date = calendar.previous_session(today)
        with engine.begin() as conn:
            reconcile(conn, trade_date, now_utc=now_utc, model_version=model_version)
        ping_success(hc)
        return "reconciled"
    except Exception as exc:
        ping_fail(hc, f"reconcile {today}: {exc!r}")
        raise
```
Note on `run_refit_job` fit_date: `previous_session(today+1)` yields the last session on-or-before today (Friday's session when fired Saturday; today's session if fired on a session day). This is intentional and robust to the fire landing on a weekend.

```python
    if direction == "down":
```
