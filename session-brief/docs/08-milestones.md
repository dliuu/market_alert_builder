# 08 — Milestones

Sequenced. Each has a definition of done that is testable, not vibes.

- [x] **M0 — Scaffold.** Monorepo, both apps boot, Supabase connected, Alembic runs, `pnpm contracts:gen` produces both generated files and CI fails when they're dirty.
- [x] **M1 — Book CRUD.** Sectors, holdings, lots in Next.js. *Done when:* you enter your real book and it survives a redeploy.
- [x] **M2 — Ingest + normalize.** One vendor behind `MarketDataProvider`. *Done when:* `bars_daily` fills nightly for your symbols and a replay from `raw_payloads` reproduces it byte-for-byte.
- [x] **M3 — Compute: returns, P&L, contribution.** *Done when:* numbers tie out against your broker to the cent, and `Σ contribution_bps == book day_bps` in a property test.
- [x] **M4 — Assemble → BriefObject → web page.** *Done when:* you can read a close brief at `/briefs/<date>-close` and a snapshot test asserts the object from a frozen fixture.
- [x] **M5 — Suppression + tape quality.** *Done when:* a quiet session produces a visibly shorter brief and the roll-up line names the skipped tickers.
- [x] **M6 — Claims + resolution.** *Done when:* the close brief scores the same day's open brief and outcomes persist in `claims`.
- [x] **M7 — Flags: position risk + correlation.** *Done when:* thresholds fire correctly on a synthetic fixture and the weekly rate limit holds across three consecutive briefs.
- [x] **M8 — Narration.** *Done when:* prose appears, and revoking the Claude API key still produces a valid, sendable brief.
- [x] **M9 — React Email + Resend + DNS.** *Done when:* it lands in your inbox looking like the design reference, in Gmail *and* Outlook, under 80KB, with a plaintext part.
- [ ] **M10 — Scheduler + dead-man's switch.** *Done when:* it runs five consecutive sessions untouched, including one market holiday it correctly skips.
- [ ] **M11 — Return attribution (walking skeleton).** Two-factor (market + raw theme) decomposition over point-in-time, leave-one-out baskets, with PM-synthesize / AM-reconcile plumbing; CLI-driven, scheduler-ready. *Done when:* given a seeded theme and 120 sessions of bars, `attribution refit` then `score` produces additive (`market + theme + resid == total`), snapshot-stable residuals for held names; a synthetic PM run followed by an AM reconcile against a divergent official bar flips `revised` and converges; the null-test (shuffled calendar → flat residuals) and known-answer (earnings-day → large residual) tests pass. Orthogonalization, robust scaling, and consumers are M12/M13. See `docs/superpowers/specs/2026-08-13-m11-attribution-design.md`.
- [ ] **M12 — Return attribution: econometric core.** Replace the M11 estimator with the four load-bearing choices — sequential orthogonalization (residualize the basket on the market before the second stage), robust Huber+EWMA (~60d half-life) fit, MAD residual scaling (`resid_z`), and contaminated-day fit-exclusion (earnings / ex-div / index-event days, still scored) — plus stored diagnostics (β SE, residual autocorrelation, condition number, R²-collapse), capped/liquidity-screened baskets, derived signals (β drift, theme dispersion, rolling α, residual momentum), and fractional multi-theme loadings (multi-factor, M12b). Introduces `numpy`; bumps `ATTRIBUTION_MODEL_VERSION` to 2. *Done when:* on the M11 fixture, orthogonalization lowers the design-matrix condition number and stabilizes `β_theme`; Huber+EWMA blunts a planted earnings gap while it still scores a large residual; `resid_z` (MAD) scores a fat-tailed event materially higher than stdev would; additivity and version-1 history are preserved. No BriefObject change. See `docs/superpowers/specs/2026-08-13-m12-attribution-econometrics-design.md`.
- [ ] **M13 — Return attribution: consumers, scheduling, object bump.** Wire the M11 stages into the scheduler (weekend refit, 18:30 PM score, AM reconcile, each with its own Healthchecks check); carry the residual decomposition into the BriefObject (first `schema_version` bump of the feature) so the close brief ranks by `|resid_z|` and leads `one_thing` with the top residual; re-point the read-through grader at the realized residual (beta earns no credit); surface R²-collapse as a `theme_misfit` maintenance flag; add event-concordance validation. Anatomy/filings/options-divergence are exposed as trigger seams only. *Done when:* a scheduled PM→AM→weekend cycle runs untouched; the close brief leads with the top-residual name and renders the decomposition in Gmail + Outlook (<80KB) and web with old renderers intact and `pnpm contracts:gen` green; a claim right on raw return but wrong on residual resolves `wrong`. See `docs/superpowers/specs/2026-08-13-m13-attribution-consumers-design.md`.

**M3 is the one to be pedantic about.** If contribution bps don't sum to the book return, every downstream insight is quietly wrong and you won't notice for a month.

**M0–M8 need no email at all.** Resist wiring delivery early.
